# Сравнительный анализ систем геокодирования: Яндекс.Геокодер, DaData, GigaChat

**Дата:** 21.05.2026
**Цель:** На основании изучения API-контрактов, документации и практических замеров принять обоснованное решение о выборе сервиса прямого и обратного геокодирования.

---

## 1. Объект исследования

Сравниваются три сервиса принципиально разной природы:

| Сервис | Тип | Назначение |
|---|---|---|
| **Яндекс.Геокодер** | Специализированный геокодер (HTTP API) | Прямое и обратное геокодирование, мировое покрытие |
| **DaData** | Сервис стандартизации адресов РФ | Геокодирование + нормализация по ФИАС/КЛАДР, только Россия |
| **GigaChat** | Большая языковая модель (LLM) | Универсальный чат-бот; геокодера как такового не имеет |

Ключевая особенность сравнения: GigaChat не является геокодером. Геокодирование выполняется через текстовый запрос к языковой модели (`model: GigaChat`, версия `GigaChat:2.0.28.2`). Это позволяет оценить, способна ли LLM заменить специализированный геокодер.

---

## 2. Исходные данные

Использован файл `Геоданные.xlsx` с двумя наборами:

- **100 адресов** — для прямого геокодирования (адрес → координаты). Адреса охватывают Москву, Санкт-Петербург и города России от Калининграда до Анадыря. Перед обработкой данные очищены от посторонних префиксов-нумерации.
- **100 географических координат** — для обратного геокодирования (координаты → адрес).

---

## 3. Методология

**Выполнение запросов.** Все запросы к API выполнены в Postman. Использован встроенный механизм Collection Runner: запрос-шаблон прогонялся по 100 строкам входного CSV-файла. Для каждого из трёх сервисов настроено два запроса (прямое и обратное геокодирование) — всего 6 запросов, 600 обращений к API.

**Контракты API.**

- Яндекс.Геокодер — `GET https://geocode-maps.yandex.ru/v1/`, авторизация по `apikey`.
- DaData прямое — `POST .../clean/address` (стандартизация), авторизация `Token` + `X-Secret`.
- DaData обратное — `POST .../geolocate/address` (подсказки), авторизация `Token`.
- GigaChat — `POST .../chat/completions`, предварительно получается OAuth-токен (срок жизни 30 минут).

**Метрики.**

- Для прямого геокодирования расхождение координат измерялось по формуле гаверсинуса (расстояние на сфере, в метрах). Совпадением считается попадание точек в заданный радиус.
- Поскольку независимого эталона координат нет, в качестве эталона принята согласованная позиция Яндекса и DaData: там, где два профессиональных геокодера расходятся менее чем на 100 м, их усреднённая точка считается достоверной.
- Для обратного геокодирования сравнение проводилось на уровне населённого пункта (совпадение города).

---

## 4. Результаты: прямое геокодирование (адрес → координаты)

Все три сервиса вернули координаты для всех 100 адресов. Различие — в точности.

**Собственная оценка точности геокодерами:**

| Сервис | Точно | С точностью до дома/улицы | Приблизительно |
|---|---|---|---|
| Яндекс (`precision`) | 84 — `exact` | 14 — `number` | 2 — `near` |
| DaData (`qc_geo`) | 83 — код `0` | 13 — код `1` | 4 — код `2` |

**Попарное расхождение координат:**

| Пара сервисов | Медиана | Среднее | Совпали <100 м | <500 м | <1 км | Грубых ошибок >50 км |
|---|---|---|---|---|---|---|
| Яндекс ↔ DaData | **7 м** | 212 м | 92 % | 97 % | 97 % | 0 |
| Яндекс ↔ GigaChat | 3 619 м | 116 851 м | 0 % | 4 % | 13 % | 19 |
| DaData ↔ GigaChat | 3 618 м | 116 866 м | 0 % | 4 % | 13 % | 19 |

**Ошибка GigaChat относительно эталона** (согласованная позиция Яндекс+DaData, 92 адреса):

- Медианная ошибка — **3,6 км**; в пределах 1 км — лишь 13 % адресов.
- У 41 адреса ошибка превышает 5 км, у 10 адресов — более 100 км (точка попадает в другой регион).
- Среднее значение (≈125 км) сильно завышено грубыми промахами и не является показательным.

**Вывод по прямому геокодированию.** Яндекс и DaData дают практически идентичный результат (медиана расхождения 7 м) — это взаимно подтверждает их достоверность. GigaChat пригоден лишь для грубой оценки на уровне города-региона: точные координаты дома он не определяет, а в каждом десятом случае ошибается катастрофически.

---

## 5. Результаты: обратное геокодирование (координаты → адрес)

| Сервис | Получено адресов | Совпадение по городу с Яндексом | Уникальных ответов из 100 |
|---|---|---|---|
| Яндекс | 100 / 100 | эталон | 98 |
| DaData | 96 / 100 | **100 %** | 94 |
| GigaChat | 100 / 100 | **12 %** | 71 |

DaData не нашёл 4 точки (№ 52, 53, 71, 96) — координаты попали в нежилые зоны (акватория, парк, окраинные территории). Это следствие неполного покрытия по малым территориям, а не ошибка.

Совпадение Яндекса и DaData по городу — 100 % (на всех точках, где оба дали ответ). Оба сервиса корректно восстанавливают населённый пункт и улицу.

GigaChat совпал с профессиональными геокодерами по городу лишь в **12 %** случаев — то есть в 88 точках из 100 назвал неверный город. Модель не анализирует координаты, а генерирует правдоподобный адрес: ответ «Москва, Ленинградский проспект, д. 80» был выдан 14 раз для 14 разных точек по всей стране. Из 100 запросов получено лишь 71 уникальное значение.

**Вывод по обратному геокодированию.** Яндекс и DaData надёжны; Яндекс выигрывает по полноте (100 против 96). GigaChat для обратного геокодирования непригоден полностью — его ответы не связаны с входными координатами.

---

## 6. Профиль каждого сервиса

**Яндекс.Геокодер.** Профессиональный геокодер с мировым покрытием. В тесте — 100 % полнота по обоим направлениям, высокая точность. Минусы: с 2024 г. геокодер платный, бесплатный тариф ограничен (в тесте — лимит 1000 запросов); ключу требуется некоторое время на активацию.

**DaData.** Специализированный сервис для адресов РФ. Точность на уровне Яндекса; дополнительно возвращает почтовый индекс, идентификаторы ФИАС/КЛАДР, коды качества (`qc_geo`) и стандартизованный вид адреса. Бесплатный тариф щедрый — 10 000 запросов в сутки. Минусы: только Россия; обратное геокодирование имеет пропуски на малозаселённых территориях (96 % полнота).

**GigaChat.** Языковая модель, геокодером не является. Пригоден максимум для грубой оценки региона по адресу; для обратного геокодирования и для определения точных координат непригоден. Требует отдельного механизма OAuth-токенов.

## 8. Выводы и обоснование выбора

1. **GigaChat исключается.** Языковая модель не выполняет геокодирование: при прямом геокодировании медианная ошибка 3,6 км и 10 грубых промахов из 100, при обратном — совпадение по городу лишь 12 %. Использование LLM вместо специализированного геокодера недопустимо.

2. **Яндекс.Геокодер и DaData равнозначны по точности** — медианное расхождение между ними 7 м, согласие по городу при обратном геокодировании 100 %. Оба сервиса подходят для производственного использования.

3. **Рекомендуется DaData** как основной сервис прямого и обратного геокодирования. Обоснование: задача работает с адресами на территории России, где DaData обеспечивает точность на уровне Яндекса и дополнительно даёт стандартизацию по ФИАС/КЛАДР, почтовые индексы и коды качества — данные, необходимые для корректной работы с российскими адресами. Бесплатный лимит DaData (10 000 запросов в сутки) на порядок выше, чем у Яндекса.

4. **Яндекс.Геокодер рекомендуется как резервный сервис** — для обратного геокодирования в малозаселённых зонах, где у DaData есть пропуски, а также при необходимости работать с адресами за пределами РФ.

---

## 9. Ограничения исследования

- Независимый эталон координат отсутствовал; за эталон принята согласованная позиция Яндекса и DaData, что корректно при их взаимном подтверждении, но не является абсолютной истиной.
- Выборка — 100 адресов и 100 координат; для производственного решения желательна большая выборка.
- Сравнение обратного геокодирования проводилось на уровне города; совпадение на уровне дома не оценивалось из-за различий в форматировании адресов разными сервисами.
- Результат GigaChat зависит от формулировки запроса и версии модели (`GigaChat:2.0.28.2`).
